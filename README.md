# Bakery-Inventory-App

A simple bakery inventory app created using Python and Tkinter to add and keep track of bakery items.
For this project, I created a simple bakery inventory program using Python and Tkinter. The program allows users to enter bakery items, add them to a list, and keep track of the total number of items entered.

**#What the app includes:
Text field to enter bakery items
Add button to add items to the list
Warning message if the input is empty
Listbox to display entered items
Scrollbar to move through the list
Counter to show the total number of items
Quit button to close the program

**#What I learned:
Creating a GUI using Tkinter
Using functions and buttons
Working with Entry and Listbox widgets
Using message boxes for warnings
Updating labels based on user input
